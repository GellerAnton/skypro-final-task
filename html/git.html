Git

  • git init - команда для инициализации нового репозитория Git в текущей папке.
  • git status - показывает текущий статус изменений в рабочей директории и индексе.
  • git add [файл или папка] - добавляет изменения в указанный файл или папку в индекс для будущего коммита и т.д.
  • git commit — сохранение изменений в локальном репозитории
  • git push - отправляет измененные файлы в удаленный репозиторий
